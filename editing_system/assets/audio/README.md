# Class 7: Audio Libraries (`audio/`)

Curated local CC0/royalty-free sound effects and music beds governed by `../../rules/03-audio-and-sfx.md`.

## Planned Organization

- `sfx/whoosh/` — Restrained section-transition air swells.
- `sfx/pop/` — Soft card/callout arrival ticks.
- `sfx/ui_click/` — Crisp subtle UI emphasis clicks.
- `sfx/soft_hit/` — Low-key milestone markers.
- `sfx/riser/` — Short buildup cues ahead of major reveals.
- `music/` — Low-distraction instrumental beds.

## Storage & Git Note

Root `.gitignore` ignores `*.wav` files globally. Store lightweight curated `.mp3`/`.ogg` SFX assets intentionally with verified CC0/royalty-free license metadata in `../catalog.json`, or store full multi-track packs in the external media archive per [CONTENT_ASSETS.md](../../../CONTENT_ASSETS.md).
