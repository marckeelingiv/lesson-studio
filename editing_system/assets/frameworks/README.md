# Class 3: Infographic & Framework Kit (`frameworks/`)

Reusable diagram and concept templates mapped to 5 structural framework families. Every template inherits palette, border, and typography variables from `../tokens/`.

## 5 Framework Families & Starter Pack v0.1 Targets (Phase 2)

1. **Linear (`linear-steps`)**: Sequential step flows, data pipelines, timelines, and acronyms.
2. **Non-Linear (`non-linear-pillars`)**: Segmented rings, independent pillars, and radial system hubs.
3. **Cyclical (`cyclical-loop`)**: Feedback loops, compounding workflows, and iterative cycles.
4. **Hierarchical (`hierarchical-tree`)**: Trees, architecture stacks, pyramids, and storage/compute tiers.
5. **Matrix (`matrix-2x2`)**: 2x2 tradeoff grids, comparisons, Venn diagrams, roadmaps, and leaderboards.

Add new specialized framework templates incrementally as lesson scripts require them, registering each in `../catalog.json` under `class: "frameworks"`.
