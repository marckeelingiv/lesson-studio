# Class 6: Static Graphics, Icons & Mockups (`graphics/`)

Vector icons, tool logos, SVG marks, and clean device/UI frame containers.

## Starter Assets

- `mockups/browser-frame.svg` (`gfx-browser-frame`) — Clean 16:9 browser window shell for framing verified web UI/dashboard captures.
- `mockups/terminal-frame.svg` (`gfx-terminal-frame`) — Clean 16:9 terminal window shell for framing CLI runs, SQL, and logs.

## Intake & Storage Policy

- Keep lightweight, crisp SVGs and verified MIT/CC0 icons (e.g., Lucide or Tabler icons added on demand as lessons need them) inside `graphics/icons/` or `graphics/logos/`.
- Record `license` and `attribution` for every asset in `../catalog.json` under `class: "graphics"`.
- Store heavy raster media or B-Roll video clips outside Git in the media archive per [CONTENT_ASSETS.md](../../../CONTENT_ASSETS.md).
