# Packaging and derivatives

Read `.opencode/skills/post-production/references/handoff.md` and its sibling `tools.md`. Use stable master, captions, brief and approved claims.

1. Draft accurate titles/descriptions and final-timeline chapters. Hook promises must be fulfilled.
2. Select up to the requested number of standalone excerpts with beginning/insight/conclusion and necessary caveats. Return fewer or none with reasons rather than forcing clips.
3. Supply parent intervals and original-source mappings. Plan readable layouts, not automatic center crops of dense UI; request pickups where necessary.
4. Prepare derivative previews with zero-based captions and explicit delivery/mix settings using producer-owned inputs. Verify current platform constraints from official sources.
5. Supply thumbnail concepts and existing still candidates with provenance. Image generation, asset acquisition and publication require authorization when not already requested.

Done when copy, chapters, selections/layouts and available previews are documented in `report.md` against the exact parent revision. A concept is not a finished thumbnail; each export still needs QC.
