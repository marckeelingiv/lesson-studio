# Lesson Studio

- Read `../LESSON_FRAMEWORK_MISSION.md` first for the overall mission, scope, recording process, and portability requirements.
- Read `README.md` for serving, authoring, capture limitations, and the pipeline handoff.
- Preserve the private presenter / clean audience boundary. Safe-zone guides appear only in the preview.

- Use Node's standard library and native browser APIs unless a demonstrated requirement needs more. No build/install step is currently required.
